Windows · read-only disk scanner

Find what's safe to remove.
Without removing it.

Scoria walks your drive, applies deterministic rules, and reports what looks unused with reasons and confidence. It has no delete, move, or rename path.

Download for Windows How it stays safe

No installer. One portable .exe. Windows 10 or later.

It cannot delete

There is no delete, move, rename, or shell file-operation path in the tool. Recommendations are text, not commands.

It sends nothing

No network access, no telemetry, no crash reports. Rules-only results work fully offline.

Metadata only by default

The normal scan reads file metadata, never contents. Duplicate verification is opt-in with -dupes and reads only same-size candidates.

It can drop privileges

-low-integrity lowers the process before scanning, so a bug cannot write to most of the user profile. File report output is disabled in that mode.

What it finds

  • Generated directories such as node_modules, __pycache__, .venv, and build outputs
  • Large and old files, with protected paths withheld
  • Temporary and crash-dump extensions
  • Size-only duplicate leads, and content-verified duplicate groups when you ask for them
  • What it skipped: reparse points, permission denials, cloud placeholders, and long paths

What it will not do

  • It will not recommend anything under Windows, Program Files, restore points, $Recycle.Bin, or Recovery
  • It will not read files by default, and it will not hydrate cloud placeholders
  • It will not call the cloud, collect telemetry, or upload a report
  • It will not tell you a file is "safe to delete." It says what looks unused and why

Quick start

scoria -root C:\Users\me
scoria -interactive
scoria -root C:\Users\me -html scoria-report.html
